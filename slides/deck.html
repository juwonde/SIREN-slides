Background · Space environment

Charged particles around a LEO CubeSat

  • Trapped particles (Van Allen belts)
    • inner belt: protons, tens–hundreds MeV
    • outer belt: electrons, 0.1 to several MeV
    • SAA: inner belt dips to LEO altitude
  • SEP events
    • flares · CME-driven shocks
    • NOAA S1: ≥ 10 MeV protons ≥ 10 pfu
    • onset within minutes to hours
  • Hazards: single-event effects · charging · dose
pfu: particles cm⁻² s⁻¹ sr⁻¹ · CME: coronal mass ejection
→ Particle risk changes within minutes: detect it on board (PD)

Background · Science data

Predictive compression of particle counts

  • CR = original size / compressed size
  • Predictive coding
    • predict next sample, code only residual
    • better prediction → smaller residual
  • Zigzag: signed → unsigned
    • 0, −1, 1, −2 → 0, 1, 2, 3
  • BZ2 entropy coding
  • Decoder repeats the same prediction
CR: compression ratio · BZ2: BWT + MTF + RLE + Huffman coding
→ Good predictor = small residuals = small packets (GRU)
PADO-SAT · SIRENPreliminary
  • residuals cluster near zero → entropy coder works well
  • same predictor on ground → reconstruction
Background · Deep learning

Time-series models in SIREN

ModernTCN (Luo & Wang, ICLR 2024) → PD, BUS

  • large-kernel depthwise conv: long context
  • ConvFFN1 / 2: features / variables
  • only conv, norm, GELU

GRU (Cho et al., 2014) → compression

  • gates r, z: what to keep
  • h(t) = (1 − z) ⊙ h(t−1) + z ⊙ h̃(t)
  • one step per sample: streaming
→ Both models reduce to convolutions and matrix products: FPGA-friendly
PADO-SAT · SIRENPreliminary
  • ModernTCN: separate time, feature, variable mixing
  • GRU: small recurrent cell, predicts next count
Background · Hardware

Integer inference on an FPGA

Quantization

  • real value ≈ scale × integer
  • QAT: quantizers inside training
  • 8-bit weights · 8/16-bit activations
    • mixed precision per layer
  • exact integer MAC, wide accumulator
  • integer reference = bit-exact oracle
QAT: quantization-aware training · MAC: multiply-accumulate
FINN: open-source dataflow compiler (AMD Research)
GOPS = 2 × MACs per inference / inference time
→ Integer models make FPGA outputs checkable bit for bit
PADO-SAT · SIRENPreliminary
  • QAT keeps accuracy at 8 bit
  • dataflow: fast, many LUTs · shared engine: one MAC array reused
Background · Method

How SIREN is built

  • Declared bit width of every layer kept, never narrowed
  • Shared engine only if faster than FINN and outputs identical
  • All other layers: FINN-generated streaming operators
→ Speed from hardware, correctness from the integer reference
PADO-SAT · SIRENPreliminary
  • same six steps for all three models
  • engine mapping needs both speed and identical output

Appendix · Q&A

Why an FPGA SoC?

  • ≤ 5 W peak budget of a 3U CubeSat
  • Deterministic latency · bit-exact integer outputs
  • Configuration memory scrubbing (SEM) · watchdogs
  • ARM (Linux) + FPGA fabric in one chip
  • Flight unit: Z7000-P3 with carrier board and shielding

Appendix · Q&A

How is correctness verified?

  • Integer reference model from QAT = oracle
  • Board outputs compared byte by byte
    • PD: 16,692 outputs
    • BUS / PD: 1,391 frames
    • 3 h continuous run: 10,260 batches
  • Shared engine adopted per structure only after full-corpus match
