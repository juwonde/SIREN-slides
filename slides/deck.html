Introduction · Problem

Small science satellites share a narrow downlink

  • Earlier missions: particle detector + EO camera, or + solar observation
    • all payloads share one downlink
  • In operation: link too small for all raw data
    • data wait for ground passes
    • particle risk, equipment faults seen hours later
  • PADO-SAT: S-band margin for CREST + SIREN
    • raw data and AI results downlinked
    • → verify onboard AI against the ground
EO: Earth observation · CREST: up to 50 MB/day

Charged particles around a LEO CubeSat

  • Trapped particles (Van Allen belts)
    • inner belt: protons, tens–hundreds MeV
    • outer belt: electrons, 0.1 to several MeV
    • SAA: inner belt dips to LEO altitude
  • SEP events
    • flares · CME-driven shocks
    • NOAA S1: ≥ 10 MeV protons ≥ 10 pfu
    • onset within minutes to hours
  • Hazards: single-event effects · charging · dose
pfu: particles cm⁻² s⁻¹ sr⁻¹ · CME: coronal mass ejection
Orbit assumed from recent Nuri launches · rideshare: final orbit set by the primary payload

Background · Science data

Predictive compression of particle counts

  • CR = original size / compressed size
  • Predictive coding: send only what the predictor misses
  • 3 candidates per block and channel
    • raw · delta · GRU residual → smallest kept
  • Decoder repeats the same prediction
CR: compression ratio · zigzag: 0, −1, 1, −2 → 0, 1, 2, 3 · BZ2: BWT + MTF + RLE + Huffman
Ref. BWT: Burrows & Wheeler, DEC SRC Report 124 (1994)
PADO/SIRENPreliminary
  • residuals cluster near zero → entropy coder works well
  • same predictor on ground → reconstruction
Background · Deep learning

Time-series models in SIREN

ModernTCN → PD, BUS

  • large-kernel depthwise conv: long context
  • ConvFFN1 / 2: features / variables
  • only conv, norm, GELU

GRU → COMP

  • gates r, z: what to keep
  • h(t) = (1 − z) ⊙ h(t−1) + z ⊙ h̃(t)
  • one step per sample: streaming
Ref. ModernTCN: Luo & Wang, ICLR 2024 · GRU: Cho et al., EMNLP 2014
PADO/SIRENPreliminary

  • GRU: small recurrent cell, predicts next count
Background · Hardware

Quantization: from float to integer

  • Real value ≈ scale × integer
  • QAT: quantizers inside training
  • 8-bit weights · 8/16-bit activations
    • mixed precision per layer
  • Exact integer MAC, wide accumulator
  • Integer reference = bit-exact oracle
QAT: quantization-aware training · MAC: multiply-accumulate
GOPS = 2 × MACs per inference / inference time
Ref. QAT: Jacob et al., CVPR 2018
PADO/SIRENPreliminary
  • QAT keeps accuracy at 8 bit
  • integer model defines the correct output, bit for bit
Background · Hardware

FINN: one hardware block per layer

  • FINN: open-source compiler (AMD Research)
    • quantized network → FPGA accelerator
  • GPU: temporal architecture (SIMT)
    • all layers take turns on shared SMs
  • FINN: streaming architecture
    • one block per layer, all busy at once
    • parallelism per layer: PE × SIMD
  • Shared engine: single computation engine
    • SIREN: only where faster than FINN
SIMT: single instruction, multiple threads · SM: streaming multiprocessor · PE: processing element
Ref. Sze et al., Proc. IEEE 2017 · Venieris et al., ACM CSUR 2018 · FINN: Umuroglu et al., FPGA 2017
PADO/SIRENPreliminary
  • GPU: same SMs reused layer after layer · FINN: each layer gets its own hardware
  • SIREN mixes both styles on one FPGA
Background · Method

How SIREN is built

  • Declared bit width of every layer kept, never narrowed
  • Shared engine only if faster than FINN and outputs identical
  • All other layers: FINN-generated streaming operators
  • All results measured on the lab testbed: TE0715 SoM + TE0705 carrier board
PADO/SIRENPreliminary
  • same six steps for all three models
  • engine mapping needs both speed and identical output

Appendix · Q&A

Why an FPGA SoC?

  • ≤ 5 W peak budget of a 3U CubeSat
  • Deterministic latency · bit-exact integer outputs
  • Configuration memory scrubbing (SEM) · watchdogs
  • ARM (Linux) + FPGA fabric in one chip
  • Flight AI Processing Unit: carrier board and shielding included
PADO/SIRENAppendix
Appendix · Q&A

How is correctness verified?

  • Integer reference model from QAT = oracle
  • Board outputs compared byte by byte
    • PD: 16,692 outputs
    • BUS / PD: 1,391 frames
    • 3 h continuous run: 10,260 batches
  • Shared engine adopted per structure only after full-corpus match
