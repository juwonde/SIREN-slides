# 운용모드 통합 검토 부록

Figma 본편의 현재 운용 목표는 그대로 두고 부록 30–32쪽에 통합 검토 자료를 추가했다. 본편 20장, 부록 17장, 숨김 6장이다.

| 쪽 | 내용 | 재사용 자료 |
|---|---|---|
| 30 | 궤도당 하나의 운용 창, 전체 전력 타임라인 | 기존 A4 3쪽의 원본 차트 상단 |
| 31 | AI 추론·UART 송신·종료 확대, 단계별 표 | 같은 차트 하단과 A4 단계 표 |
| 32 | 주간 처리와 궤도 통합 비교 | A4 5쪽 비교 표와 주간 에너지 막대 |

원본은 [운용모드 통합 A4 자료](https://www.figma.com/design/A787paL5qs7eAsxJnybGEC)다. 10/24에 현재 3–5쪽의 값을 직접 읽었다. 로컬의 초기 um4 보고서(554초, 주간 +3.8%) 대신 A4의 갱신된 oc5 + fx7 분석(327.3초, 주간 +1.23%)을 따랐다. 원본 이미지 `57:18`의 원시 PNG를 가져와 상·하단을 Figma 프레임으로 나눠 표시했다. 새로 실험하거나 파형을 생성하지 않았다. 표와 막대는 같은 값·구조를 유지하면서 발표자료의 글자 크기와 영어 라벨에 맞췄다.

## 수치와 범위

- 통합안은 327.3초 / 600초 창, 961 J = 약 0.267 Wh/궤도다. 대표 DNN 관측 최대는 4.96 W다.
- DNN(PL 적재 포함) 4.8초 / 18.8 J는 단계 분해와 궤도별 작업량 환산이다. UART 12.2초 / 36.9 J는 실측 바이트당 비용을 결과 101,689 B에 적용한 환산이다. 정상 종료 9.27초 / 27.9 J는 실측 구간이다.
- 주간 처리+완전한 UART 결과 송신 방식은 101,265 J / 28.13 Wh, 통합안은 102,507 J / 28.47 Wh다. 차이는 반올림 전 J 기준 1,242 J / 0.345 Wh / 1.23%다.
- 비교 조건은 94.5분/궤도, 106.7궤도/주, PD 50 MB/일, 궤도 입력 3.28 MB, CAN 500 kbit/s, 데이터 목표 100 kbit/s, 실효 98.8 kbit/s, UART 115200 baud, 운용 사이 전원 OFF다. 최신 본편의 gzip 수신 시험과 조건이 다르다.
- AI 직후 PL을 깊은 대기로 복귀시키는 전제다. 원본 분석에서 이 복귀가 없으면 궤도당 19.4 J가 추가된다.
- 비교 표의 주간 별도 작업 1,505.9초에는 결과 10.83 MB의 완전한 UART 송신을 포함한다. AI 계산만은 146.5초다. 본편의 주 1회 이상·주당 3분 AI 목표를 변경한 것이 아니다.
- 결과 지연 비교는 위성 내부에서 결과가 준비되는 주기를 뜻한다. 실제 지상 전달 지연은 지상국 가시성·다운링크 운용에 달려 있다.
- 실측 구간을 결합한 환산이며, 단일 궤도 분량의 연속 E2E 시험과 비행 운용 승인은 미확인이다. 반복 100 Hz 세션의 단일 샘플 최대 5.05 W도 표기했다. 현행 5 W 요구조건 변경이나 모든 조건에서의 peak 보장을 뜻하지 않는다.
