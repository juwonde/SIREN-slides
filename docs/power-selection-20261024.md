# 10/24 발표용 전력·운용 결과

16쪽 왼쪽 아래 누적 에너지 그림의 0–117.7초 구간에 음영을 추가했다. 같은 전력 표본을 적분한 작업 완료 시점의 에너지는 337.95 J = 0.093875 Wh이며, 발표 표기는 **0.094 Wh (338 J)**다. 이 값은 수신·전처리·저장 완료까지의 누적량이고, 대기를 포함한 전체 600초의 0.475 Wh와 구분한다.

Figma 본편 5, 15, 16, 18쪽 및 관련 발표 노트에 반영했다.

## 참조 스레드의 후속 수신 시험 반영

`01a16641-1938-7743-88c7-5adaa893c4f9`의 10/24 최종 시험을 확인하여, 15·16쪽의 수신 결과와 18쪽 요약을 아래 값으로 갱신했다. NN 대표 실행은 기존 Quiet 주간 실행을 유지한다.

측정 창은 부팅·설정·종료와 NN 추론을 제외한다. 아래 기존 `oc5`의 3.28 MB, 부팅·종료 포함 약 311초와 입력 및 측정 범위가 달라, 311→118초를 동일 조건의 속도 개선으로 표현하지 않는다. 0.475 Wh는 대기를 포함한 600초의 값으로, 기존 0.2515 Wh/cycle과 직접 비교하지 않는다.

동일한 입력과 설정의 직전 `D_gzip` 시험 대비 불필요한 PL 재기동을 생략했을 때 관측 최대가 4.695→3.766 W로 19.8% 낮아졌다. 평균 변화는 약 5 mW에 불과하며 반복 시험이 없어 평균 개선 효과로 단정하지 않는다. 전체 세션의 부팅 포함 최대 5.047 W는 이 600초 창 밖의 값이다. 새 NN 전력·GOPS/W 결과로 사용하지 않는다.

## 선택 기준

- 모드 통합 실험(`um*`, `fx*`)은 제외한다.
- 세 모델 모두 50 GOPS 이상이고 정수 기준 출력과 일치한 분리 모드 실행 중, 관측된 최대 입력전력이 가장 낮은 실행을 대표로 선택한다.
- 선택: `weekly-quiet-r32boot2.json`, `wk-quiet-r32`, `bpg-r32e`, 2026-10-22 KST. Quiet 주간 데이터의 **최선 관측 실행**이며, 모든 데이터·온도 조건의 상한을 뜻하지 않는다.
- 전체 수신 창은 최신 단독 다운로드 사이클 `oc5`(2026-10-23 KST)를 사용한다.
- 서로 다른 ADC 설정의 고속 측정이나 통합 모드 실험은 이 대표 실행의 값과 섞지 않는다.

전력은 INA228으로 측정한 TE0705 + TE0715 개발용 보드의 12 V 입력이며, 측정기 자체 전원과 별도 팬 전원은 제외한다. 표의 최대는 100 Hz 샘플 중 최대다. 주간 운용 시간은 측정한 부팅·처리·종료 구간의 합계로, 시험용 업로드·baseline·결과 회수는 제외한다. 결과 송신까지 포함한 전체 임무 시간은 아니다. 다운로드 원본 단계 합계는 310.84 s이며, 그림은 동일 사이클의 운용 구간 310.34 s를 사용한다.

AI 추론 운용은 사용자의 10/24 정정에 따라 **주 1회 이상, 주당 3분**이 목표다. 추론 duty 2% 또는 궤도당 약 2분이라는 해석과 그에 따른 0.66 Wh/orbit·2.7% 합산치는 폐기한다. 수신·전처리는 98.8분 궤도의 10%에 평균 3 W를 적용해 0.494 Wh/orbit, AI 추론은 주당 3분에 peak 5 W를 적용해 최대 0.25 Wh/week로 표시한다. 서로 다른 운용 주기의 계획 배정이며 실측 에너지와 구별한다.

기존 16쪽(페이지 분리 후 17쪽)의 오른쪽 아래는 위쪽과 **동일한 전력 기록**의 20.454–40.564초를 3–5 W 범위로 확대했다. 파란 준비 구간부터 AI #1의 첫 10초까지 보여준다. 우하단 누적 에너지 확대본은 전력 확대본으로 교체했다. 2,011개 샘플을 사용했고, 각 표시 열의 최소·최대 샘플을 보존했다. 원시 샘플 범위는 2.976–4.8888 W이며 화면은 요청한 3–5 W에 한정한다. 위쪽 전체 전력 그래프와 전체 실행 150/180초, 0.17 Wh 표기는 유지했다. 생성기는 `tools/weekly_power_zoom.py`, 축약 근거는 `assets/ops/weekly-power-zoom.json`이다.

17쪽 위쪽 전체 전력 그래프에는 별도 시간축(0–180초, 30초 간격)과 `time (s)` 표기를 추가했다. 확대 범위인 20.454–40.564초에는 흰 바탕에서 약 5% 어두워지는 아주 연한 회색 음영을 파형 뒤에 넣었다. 사용자가 조정한 그래프 크기와 배치는 유지하며 현재 축의 실제 위치와 폭에서 음영·눈금 위치를 계산했다.

## 후속 전력 검토 문구

현재 수치는 상용 개발 보드 전체의 입력전력이다. 디버그 포트와 미사용 하드웨어의 전력 기여를 분리 측정하여 비행 구성의 소비전력을 구체화한 뒤, 원래 전력 예산을 추가 검토한다. 아직 분리 측정하지 않은 전력을 임의로 차감하지 않는다.
